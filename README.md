# Forest Threat Audio Classification

## Project Overview
A machine learning project that analyzes environmental audio to classify sounds associated with forest threats and natural events.

## Objectives
- Process and prepare audio recordings.
- Extract informative audio features.
- Train and compare machine learning classifiers.
- Evaluate performance using validation metrics.

## Audio Classes
The project is designed to classify audio into categories such as:
- Gunshot
- Fire
- Chainsaw or engine
- Human voice
- Rain and thunder
- Natural sounds
- Unknown sounds

## Tools & Technologies
- Python
- Librosa
- NumPy and Pandas
- Scikit-learn
- XGBoost
- CatBoost
- Jupyter Notebook

## Workflow
1. Audio preprocessing
2. Feature extraction using MFCCs and spectral features
3. Model training and validation
4. Hyperparameter tuning
5. Model comparison using macro-F1

## Models
- Support Vector Machine (SVM)
- XGBoost
- CatBoost
